# hmrdkn-labs Homebrew Tap

Public Homebrew tap for hmrdkn-labs tools.

## LazySS

```sh
brew install --formula hmrdkn-labs/tap/lazyss
```

## Agent Awake

Keeps your Mac awake while AI coding agents work, lets it sleep when they finish, and pings your phone.

```sh
brew install --cask hmrdkn-labs/tap/agent-awake
```
